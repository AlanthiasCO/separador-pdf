# Separador de PDF para PNG

Aplicacao em Streamlit que permite carregar um arquivo PDF, converter todas as paginas em PNG e baixar o resultado em um arquivo `.zip`.

## Como executar

1. Instale as dependencias:

```bash
pip install -r requirements.txt
```

2. Rode a aplicacao:

```bash
streamlit run app.py
```

## Como usar

1. Carregue um arquivo PDF na interface.
2. Clique em **Converter PDF em PNG**.
3. Baixe o arquivo `.zip` gerado com todas as paginas convertidas.
